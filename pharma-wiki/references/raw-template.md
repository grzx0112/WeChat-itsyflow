# Raw Document Template

```markdown
---
Source: {url_or_reference}
Collected: {YYYY-MM-DD}
Published: {YYYY-MM-DD or Unknown}
Title: {document_title}
---

{original_text_preserved}
```

## Rules
- File name: `raw/<topic>/YYYY-MM-DD-descriptive-slug.md`
- Preserve original text, do not rewrite
- Source URL, collection date, and published date in YAML front matter
- If same-name file exists, append numeric suffix
