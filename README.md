# 医词元工作流

> 医药垂直领域 AI 工作流合集，定期发布

**医词元工作流**是一个聚焦医药垂直领域的公众号，定期分享可直接使用的 AI 工作流。每个工作流覆盖医药研发与商业化中的一个具体场景，输入一句话即可输出结构化报告。

## 已发布

| 工作流 | 一句话说明 |
|--------|-----------|
| **pharma-deep-research** — 横纵分析法深度研究 | 输入药物/靶点/适应症，输出 8000-20000 字研报 |
| **pharma-intel-agent** — AI 药品情报聚合 | 输入关键词，自动从 FDA + PubMed + 新闻抓取，AI 过滤后生成双语情报快报 |

## 持续更新中

更多医药工作流正在路上，关注公众号「**医词元工作流**」获取最新发布。
