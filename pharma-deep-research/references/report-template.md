# 报告结构模板

> 以下为完整报告结构。根据对象类型（drug/target/indication/company/platform）调整重点章节，
> 非所有章节都必填——不适用或无数据的章节标注「暂缺」即可。

```markdown
# 【深度研报】{对象名称}｜{对象类型}｜{日期}

## 0. Executive Summary
- 一句话结论（最核心的判断）
- 关键判断 3-5 条（带方向性，不含糊）
- 最大不确定性（什么可能推翻以上判断）
- 未来 90 天观察信号（具体、可验证）
- 推荐行动（如果有明确建议的话）

## 1. 研究范围 (Scope)
- 对象定义（标准化名称、别名、代码）
- 研究边界（包含/排除的内容）
- 地域范围
- 研究目的（尽调/立项/竞品差距等）
- 数据来源与可信度说明

## 2. 纵向：全生命周期时间线

> 按 Step 2 定义的对象类型重点展开，写成因果链叙事。

### 2.1 起源与科学基础
- 靶点/机制/技术的发现背景
- 早期验证证据（为什么觉得这条路走得通）
### 2.2 关键转化节点
- 从实验室到临床的关键决策
- 失败的弯路和纠偏（如果有）
### 2.3 临床开发里程碑
- I/II/III 期各阶段的设计选择和结果
- 重要的方案调整及其原因
### 2.4 监管里程碑与标签
- 审评过程中的争议点
- 标签上的限制条件及其商业影响
### 2.5 上市后演变
- 真实世界证据
- 适应症扩展
- 竞争反应和市场格局变化

## 3. 横向：竞品与证据包对比

### 3.1 竞品地图
- 筛选逻辑（三层方法学：同机制→同适应症→同阶段）
- 入选竞品的代表性说明
- 竞品全景图（机制/阶段/适应症覆盖）

### 3.2 对比矩阵

| 维度 | 研究对象 | 竞品 A | 竞品 B | 竞品 C | 可比性说明 |
|------|---------|--------|--------|--------|-----------|
| 机制 | | | | | |
| 疗效（主要终点）| | | | | 人群/终点/随访差异 |
| 安全性 | | | | | AE 定义差异 |
| 标签范围 | | | | | |
| 给药方案 | | | | | |
| 可及性 | | | | | |

### 3.3 可比性声明
- 哪些对比是头对头（H2H），哪些是跨试验间接比较
- 跨试验比较的具体局限性
- 数据成熟度差异

## 4. 商业与投资者视角

> 此章节服务于 BD/投资/战略决策，是区别于学术报告的核心差异化内容。

### 4.1 市场定位与峰值销售预测
- 当前市场规模与增速
- 各竞品的市场份额趋势
- 峰值销售预测区间（如有分析师共识）

### 4.2 BD 交易先例
- 同领域近 2 年的主要 BD/并购交易
- 交易条款（首付/里程碑/分成）作为估值参考
- 交易时点的管线阶段和竞争格局

### 4.3 专利与独占期时间线

| 类型 | 到期时间 | 影响范围 |
|------|---------|---------|
| 物质专利 | YYYY-MM | 核心化合物保护 |
| 用途专利 | YYYY-MM | 适应症保护 |
| 制剂专利 | YYYY-MM | 剂型保护 |
| 数据独占 | YYYY-MM | 监管数据保护 |
| 孤儿药独占 | YYYY-MM | 孤儿适应症保护 |

### 4.4 估值锚点
- 可比公司的市值/企业价值与管线阶段对标
- 风险调整后 NPV 的关键假设
- 情景分析（Base/Bear/Bull 下的价值区间）

## 5. 交叉洞察

### 5.1 历史路径如何塑造当下
- 关键历史决策对当前竞争位置的因果解释
### 5.2 格局拐点
- 当前是否处于格局变化拐点
- 拐点的驱动力和方向判断
### 5.3 未来三剧本

| 剧本 | 概率 | 情境 | 触发条件 | 观察信号 |
|------|------|------|---------|---------|
| Base（最可能）| ~60% | | | 未来 90 天内可观察 |
| Bear（最危险）| ~20% | | | |
| Bull（最乐观）| ~20% | | | |

## 6. 附录

### A. 证据台账
| 结论 | 证据来源 | 日期 | 可信度 |
|------|---------|------|--------|
| ... | CT.gov NCT... / FDA label / PubMed PMID... | | 一手/二手/线索 |

### B. 参考文献
- DOI / URL / NCT 编号 / FDA 文件编号

### C. 数据采集记录
- 脚本运行时间
- 各数据源查询结果统计
- 未覆盖的数据缺口说明
```
